# Changelog

## 1.1.0 — 2026-11-12

- Added optional click-to-reveal for Feature cards and vertical action cards in
  Summary & next steps. Cards slide in gently from below during the HTML show.
  The normal preview and PDF show all cards.

## 1.0.0 — 2026-11-09

First public release line of Slidebaby, with Brite as its first registered visual template.

- 69 layout variants in 14 families, with per-slide Light/Dark.
- Agent-driven composition from finished copy, rough notes or one webpage.
- Searchable EN/PL template library and copyable localized prompts.
- Source-preserving edits, measured fit and explicit recovery proposals.
- Standalone HTML, prepared PDF, stable current files and optional editable ZIP.
- Optional brand/photo/screenshot guidance and proportional WebP ingestion.
- Local bounded Live preview and honest cloud download/refresh guidance.
- Custom Slidebaby Community License 1.0: free presentation creation and paid
  client work; no resale of the skill or its modified versions.

Development versions through 4.32 are retained in the author's earlier packages.
Their old release entries are not presented as public 1.x changes.

Slidebaby installs as `slidebaby`, with registered visual-template bundles. Brite
provides the initial visual system; saved visual-template identity is separate
from layout recipe IDs and Light/Dark. Earlier private Brite projects remain
compatible. This release does not automatically convert between visual templates.
