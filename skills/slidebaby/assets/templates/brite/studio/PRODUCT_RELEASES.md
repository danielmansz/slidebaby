# Slidebaby product and releases

Slidebaby is the product; Brite is its current template. Created and designed by
[Daniel Mansz](https://www.linkedin.com/in/daniel-mansz/). The public skill
ID/folder is slidebaby. Brite is a registered, versioned visual-template bundle;
its internal runtime globals and recipe IDs remain compatible. Keep the supplied SVG workspace logo unchanged;
user slide branding/content remain independent.

Version1.0.0 is the first public release line. The version in changelog.js and
SKILL metadata describes this copy, not an online update feed. Development history
through v4.32 is preserved in the author's earlier packages, outside this public
runtime. Public numbering does not rename the renderer, saved template IDs or
license version.

For each new product release update version/date and concise EN/PL changes in
changelog.js, skill metadata and repository release.json/CHANGELOG.md together.
Keep legacy template/source/replay compatibility and the installed starter empty.
Do not change a user's saved deck merely to publish a tool update. New projects
receive current UI; intentional older-project upgrades must verify source, fit and
matching HTML/PDF. Carry license notices without overwriting an unrelated license.

The custom Slidebaby Community License1.0 permits free presentation creation,
paid client work and actual PDF/HTML/editable-project delivery, and prohibits
resale of the skill or modified versions. LICENSE is authoritative; LICENSING.md
explains EN/PL terms. Independent font/image rights stay separate. This is
source-available, not an OSI-approved open-source license. See THIRD_PARTY_NOTICES.md.

Projects store visualTemplate identity separately from slide recipe IDs and
palettes. Product releases update the registry/manifests and release metadata;
new visual templates do not silently restyle existing projects. Recognized older
Brite projects keep their own saved runtime. Automatic cross-design conversion
and mixing distinct visual templates within one deck are not implemented.
