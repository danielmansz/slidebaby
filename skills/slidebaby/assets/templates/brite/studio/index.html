What does my agent need?

Your AI agent needs access to this project folder so it can save your slides here. This page is a preview and template library. Copying a prompt does not send it to an agent or create a slide.

How do I change my slides?

Tell your agent which slide to change and describe the result you want. Ask it to save the presentation and regenerate the PDF, then refresh this page.
